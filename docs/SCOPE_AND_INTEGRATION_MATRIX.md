## Focused increment: customer exam invitation controls

The prior customer examination detail linked into a Super Admin-only page. The branch replaces that broken link with creator-only, tenant-scoped enable/disable and link/code rotation, and moves the shared copy UI out of the admin route directory. The database generates the link and hashes the code. Advanced identity, eligibility and attempt settings remain global-only; they are explicitly identified as unavailable in the customer workspace. Updates and audit inserts are separate writes: an audit failure is surfaced as partial success and rotation must not be retried without checking current values. Mock tests cover wrong tenant, denied role, malformed action, writes, no secret in audit metadata and partial failure. Real customer browser/database acceptance remains open.
